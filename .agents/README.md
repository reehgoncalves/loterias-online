# Instruções obrigatórias do projeto

Antes de alterar qualquer regra de cobrança, aposta, prêmio, estorno, saldo,
bolão, exposição ou pagamento, leia completamente:

- [`payment-rules.md`](./payment-rules.md)

Essa leitura é obrigatória para qualquer agente ou pessoa que altere o backend,
jobs, migrations, webhooks ou painel administrativo. Se uma mudança não puder
respeitar essas regras, a alteração deve ser interrompida e revisada antes do
merge.
